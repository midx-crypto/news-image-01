A 1024x1024 newspaper front page for Friday 13 November 2026 with four stories: NVIDIA CEO Jensen Huang resigns with Colette Kress stepping in as interim CEO; Microsoft 365 goes down worldwide, taking Outlook and Teams offline in 74 countries; Europe joins the Ukraine talks as envoys confirm a seat at the table and a prisoner swap is planned; and Anthropic's IPO is oversubscribed on its first day of book building, the book about six times covered at $70-78 a share for a roughly $61B raise.

## Run it

```bash
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

This copies `entry.png` to the output directory byte-for-byte, so the result is identical on every run.
